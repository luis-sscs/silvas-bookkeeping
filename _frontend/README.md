# Silvas Accounting Frontend

React.js application for managing accounting operations with Redux state management.

## Setup

```bash
cd _frontend
npm install
npm start
```

## Features

- **Authentication**: Auto-login with test account (username: testuser, password: password123)
- **Dashboard**: Overview of revenue, customers, invoices, expenses
- **Invoices**: Create, edit, delete, and manage invoices
- **Customers**: Full CRUD operations for customer management
- **Products**: Manage products and services
- **Estimates**: Create and track estimates
- **Expenses**: Track and categorize expenses
- **Payments**: View payment history
- **Reports**: View generated reports

## Tech Stack

- React 18
- Redux Toolkit for state management
- React Router for navigation
- Axios for API calls
- Proxy configuration to backend API
